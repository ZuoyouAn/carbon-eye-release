HOW IT WORKS

理解结果，比得到结果更重要。

01

IP → 地理数据库

验证公网 IPv4 / IPv6 后，用 HTTPS 请求 ipwho.is，读取地区、ASN、运营组织、时区和估计坐标。地图保留小数精度。

坐标通常指网络出口或运营商节点。VPN、代理、移动网络和数据库更新会影响结果，不能据此确定个人住址。

02

号码 → 号段元数据

使用 phonenumbers（Google libphonenumber 的 Python 实现）离线解析国家码、号码类型、地区、运营商与格式，核对长度和编号规则。

“有效”只表示符合编号计划，不代表号码已分配或正在使用。没有机主姓名或 GPS；携号转网也会使运营商字段失准。

03

用户名 → 公开页面响应

将用户名填入 19 个固定平台的个人页地址，最多 6 个并发请求，读取 HTTP 状态。每个请求有超时，不跟随跳转。

200 仅表示页面可访问；平台可能返回登录页或软 404。不同平台的同名账号不一定属于同一个人，需打开页面人工核对。

网页版本相对原项目改进了什么？

保留原始 GhostTR.py，独立提供 JSON API 和中文界面；IP 改用 HTTPS，修复原脚本把地图坐标转成整数的问题；号码默认地区改为 CN 并可选；用户名查询去重并移除过时平台，将跳转、限制、超时与未找到分开显示。加上输入校验、超时、并发上限和每分钟查询限制。

查询值与结果仅保留在当前页面内存，不写入数据库或浏览器存储。清空或离开页面后丢弃。IP 查询会把输入地址发送给 ipwho.is；用户名会发送给所列平台；号码只在运行后端的机器解析。外部平台及服务器基础设施可能保留自己的访问日志。仅查询你有权核对的信息。
