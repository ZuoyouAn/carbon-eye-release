# Space v6：基地生存、文档转换与密码实验

## 页面与范围

- 全站浅色系统字体、留白卡片、蓝色主按钮、轻量滚动显现；尊重减少动态效果，不使用 Apple 的素材或代码。
- `/wasteland`：v6 余烬营地，基地建造与三夜生存，见下方规则。
- `/wasteland?mode=exploration`：原城市探索。WASD/方向键、Shift 冲刺、E 拾取/修复、F 急救、Esc 暂停；触屏摇杆。180 秒内搜集 4 零件、2 电芯，修复信标并撤离。暂停/失焦/隐藏页面不推进时间；卸载释放帧循环、监听器和 GPU 资源。
- `/wasteland?mode=story`：原三十天剧情、v1 存档与导出规则不变。3D 模式不保存、不上传进度；无 WebGL2 时提供剧情入口。
- `/solar-system`：独立原创八行星示意图。拖动相机、缩放、选择、深链接、暂停与近景。默认静止，隐藏页面停止动画；图形不可用时可阅读文字。大小、距离、运行速度不是物理量，圆轨道不能预测星历。
- `/life-guide`：完整 34 节、657 条冻结原文；全文搜索、原书顺序、证据/成本/收益口径过滤、12 条分页。四路并发加载静态章节，失败重试，卸载取消读取。完整保留条目来源、适用条件和备注，不提供个性化医疗/法律/金融建议，不调用模型。

新模块均懒加载，Three.js 由两个 3D 页面共享，不进入首页包；不新增云资源或费用。账号、数据库、权限、模型配置没有改动。

## v6：新玩法与本机工具

- 余烬营地默认本机单局，不持久化、不上传；五类建筑对应真实资源消耗。围墙阻挡角色并可被攻击；炮塔按放置顺序分配供电，发电机每座增加 2 电力，基地初始 1。菜地和净水站各在黎明产出 3，营地每个黎明消耗 2 食物与 2 水；不足扣耐久。维修在近距离消耗 1 木材和 1 零件，恢复最多 40 耐久。
- 三天每个循环至少 60 模拟秒；标准第 34 秒入夜，轻松第 40 秒。按钮可主动提前入夜，不跳过战斗；各夜 6/8/10 敌人，最后一夜有重型敌人。固定废墟使用 BFS 网格绕行；近身设施可被击毁。清完敌潮且时段结束才进入黎明，三选一补给期间冻结模拟；守完第三夜胜利。角色空格短程自动防卫，Shift 冲刺有冷却，不传送。低帧率帧间隔限制可能使模拟时间慢于墙钟。
- 建筑最多 32 座、放置范围距角色 7 场景单位，单位为游戏示意，不对应现实米；格位有占用、范围、资源和玩家重叠校验。桌面射线点选与可访问的格位按钮共用放置规则，手机摇杆和按钮可完成玩法。音效使用 Web Audio 程序生成，默认关闭；隐藏/失焦暂停，卸载销毁输入、画布、GPU、音频与展开滚动锁。
- `/document-tools` 支持 10MB 未加密 PDF/DOCX、最多 12 页 PDF 或 12 页重排结果。PDF→Word 的文字模式仅恢复已有文字，不做 OCR，不恢复图片、多栏、表格结构；外观模式按原页长宽比嵌入页面图片，不能编辑图片内文字。Word→PDF 使用 Mammoth 结构重排、HTML 安全预览、html2canvas 与 jsPDF 逐页图像导出，不是原生 Office 版式引擎；图像 PDF 不可搜索/不具备完整无障碍语义。复杂原版式、公式、电子签名和批注需要本机原生软件人工核对。
- DOCX 压缩目录预检限制条目数量、路径、加密、解压尺寸和压缩比；在独立 Worker 内解析，30 秒超时与主动取消，禁止外部文件、嵌入样式映射和 XML DTD。预览仅允许正文/表格/内嵌栅格图片，移除脚本、链接、外部资源。PDF.js 的 worker、CMap、标准字体由本站提供，禁用 XFA 默认功能和运行时 eval；取消或卸载销毁任务与 Blob URL。修改文字清空旧下载。用户文件不进入日志、存储或数据库。
- `/crypto-lab` 七类纯 JS 教学：AES-128 单块 10 轮与 4×4 字节矩阵；SHA-256 完整填充、消息扩展、每块 64 轮寄存器与链值；小整数 RSA 模逆/平方乘模幂；小整数 DH 双方协商；凯撒、维吉尼亚与重复密钥 XOR。流程图高亮计算阶段、单步/播放/拖动、可查看核心函数并主动下载轨迹。输入变化使旧轨迹失效，默认不保存，不上传；有限输入长度，拒绝非法参数。AES 对照 NIST 向量及 Node 独立计算，SHA 对照 Node 边界与 Unicode 消息。
- 教学页不应输入真实密码/私钥。单块 AES 没有模式/填充/认证；小整数裸 RSA、未认证且无安全子群验证的 DH、重复短密钥 XOR 均不构成安全应用。SHA 是散列，不是可逆加密，也不替代专门的密码散列/KDF。生产用途必须使用经过审查的密码库及完整协议。

新增第三方依赖固定版本：PDF.js 6.4.299（Apache-2.0）、docx 9.8.1（MIT）、Mammoth 1.13.0（BSD-2-Clause）、jsPDF 4.2.1（MIT）、html2canvas 1.4.1（MIT）、fflate 0.8.3（MIT）；打包保留依赖版权，PDF.js 数据资源附 LICENSE。实现依据 [PDF.js API](https://mozilla.github.io/pdf.js/api/draft/)、[Mammoth 安全说明](https://github.com/mwilliamson/mammoth.js#security)、[docx](https://docx.js.org/)、[jsPDF](https://github.com/parallax/jsPDF) 与 [NIST AES](https://csrc.nist.gov/pubs/fips/197/final)、[NIST SHS](https://csrc.nist.gov/pubs/fips/180-4/upd1/final)、[RSA RFC 8017](https://www.rfc-editor.org/rfc/rfc8017)、[DH RFC 2631](https://www.rfc-editor.org/rfc/rfc2631)。实现为原创建模与数学运算，不复制第三方游戏。

`scripts/check_creation_tools_browser.py` 使用合成 PDF 与依赖附带测试 DOCX 验证真实转换、OOXML 内容/图片/分节和导出 PDF 逐页图像；原生 Word 完美版式未验证，不作此承诺。游戏通过实际 UI 建造和真实防卫键完整守三夜，不注入资源/时间/位置。`--live` 同样不改云端数据。

## v5.1：持续探索与阅读

- 太阳系新增十个历史任务，按 UTC 发射日期排序；可组合目标行星、年代和关键词筛选。任务链接如 `/solar-system?planet=neptune&mission=voyager-2` 可独立打开。选择任务高亮相关行星与示意轨道，近景按钮暂停运行；不绘制航天器轨迹，不提供实时位置或当前任务状态。
- 任务档案只标记主要探测对象，不列全部助推点；每项附 NASA 来源。MESSENGER 发射按 NASA History 的 UTC 日期 2004-08-03，避免混用当地时间；旅行者 2 号先于 1 号发射。核对于 2026-10-05。
- 原文章节四路并发、逐章展示。选择或分享的章节优先加载；索引未完成时明确提示结果不完整。一章失败不隐藏其他原文，重试使用成功章节的内存缓存；离开路由取消请求。关键词搜索复用小写全文索引，完整 Markdown 仅在展开时渲染。
- 收藏和阅读定位默认只在会话内存在。用户主动开启本机保存后，`space-life-guide-reader-v1` 仅保存版本、许可标记、收藏条目编号与最后阅读编号；不存正文、查询、账号，也不上传服务器。关闭保存删除该键，但保留当前会话；清除记录删除该键并重置当前会话，保留其他存档。存储受限或损坏时降级到会话模式。
- 条目链接 `/life-guide?entry=1-13` 自动选择对应章节、页码并展开原文。筛选链接支持查询、章节、证据、收益口径、成本、性价比档与页码；不会把私有收藏列表带入 URL。浏览器前进/后退同步筛选控件。剪贴板不可用时提供可手动复制的链接。
- 原书冻结快照、许可、全部 657 条来源与备注以及性价比算法均未改动。不把阅读记录当健康数据，不添加个性化建议或模型调用。
