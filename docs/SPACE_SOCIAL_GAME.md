# 左右的Space：头像、聊天和末世模拟器

## 架构与升级边界

沿用 Vue 3 / Vite、FastAPI、Neon PostgreSQL，继续使用现有账号和分级权限，不新增付费服务、不迁移用户或重设管理员密码。新增七张独立表：`user_avatars`、`chat_rooms`、`chat_members`、`chat_messages`、`chat_blocks`、`social_quota`、`chat_throttle`。后端启动时非破坏性创建新表，不改动原文章、留言或小说数据。

头像在个人中心选择；客户端先居中裁剪到128像素，后端再次验证、裁剪、转换为静态WebP并丢弃原图元数据。接受JPEG/PNG/WebP，不接受SVG和动画；客户端源图最多5MB，服务端解码后最多256KB/400万像素，最终头像最多32KB。数据库存储唯一用户头像，重启不会丢失；公开读取带ETag和nosniff，删除账号的头像不公开。头像每日每人最多上传10次、全站100次。

## 聊天规则

- 登录且未禁言的低权限、高权限、管理员均可在公共大厅聊天。游客不能读取聊天、会话或用户搜索。禁言账号只能读取已有可访问会话。
- 高权限和管理员每日最多创建2个邀请制小群；全站20个。群主邀请，群内最多12人（包括待接受邀请）；对方接受后可读仍在30天保留期内的群历史。
- 私聊用双方用户ID建立唯一会话，必须由收件人接受邀请后才可发送。拒绝或退出后，本版本不支持再次邀请或加入；退出即失去读取权。
- 每人每日最多5次新邀请操作（建群计一次）。全站每日100次。拉黑阻止双方私聊与新邀请，保留可访问的已有历史，不能隐藏公共群消息。解除只能删除自己创建的拉黑关系。
- 每条1–1000个字符，非空纯文本，至少间隔3秒；每日每人200条、全站1000条。每日额度以UTC日期计，额度使用数据库原子更新；失败操作回滚。重试沿用消息UUID，不产生重复消息或重复计费额度。
- 每次历史读取最多50条，支持向前分页。页面可见时每12秒轮询最新窗口；离开页面停止轮询和在途读取。当前版本不是WebSocket即时通讯，没有附件、未读通知、成员移除、群主转让或手机后台推送。
- 自己可撤回消息，内容清空且不可恢复。管理员可撤回公共大厅内容；管理员不绕过群聊和私聊成员校验。
- 仅保留30天聊天消息可供读取，过期聊天在下一次成功发送时清理；原留言板、文章、小说不受此规则影响。撤回或退出不能让对方忘记已经收到的内容。
- 通过HTTPS连接并持久化存储，但**不是端到端加密**。应用管理员不能读取非成员私聊；数据库运营者仍有技术访问能力。禁止发送密码、连接串、付款信息等敏感内容。

## 末世模拟器

原创文字生存游戏，借鉴“天赋 + 属性 + 事件选择”的通用玩法，不复制其他游戏的代码、剧情、美术或名称。六种天赋选两种，四项初始属性共分配12点（单项0–8），六项资源。18类随机事件，第7/15/24/30天固定剧情；健康归零结束，活过30天可通向“灯火彼岸”“明日营地”“荒野守望”。剧情是虚构娱乐，不提供真实生存或医疗指导。

不调用模型、不消耗API额度，无需登录、无支付或排行榜。已加载页面内的游戏逻辑无需网络，但网站未提供PWA离线安装/离线首次加载。默认不保存游戏；主动勾选后在此浏览器存档，不上传云端。存档只保存版本、世界配置与行动序列，用确定性种子重新计算事件和资源，而不信任用户篡改的资源数值；这不构成防作弊系统。支持继续存档、删除本机存档和下载Markdown生存日记。

## 验证

`python -m pytest -q` 包括隔离数据库下的头像格式/大小/所有权、私聊同意、管理员无越权、群人数上限、拉黑、撤回、禁言、重试、节流/额度回滚、历史分页/保留期检查。

`cd frontend && node --test src/features/human3/engine.test.js src/features/wasteland/engine.test.js src/features/chat/history.test.js src/utils/permissions.test.js` 检查原测评/权限规则、聊天窗口/状态逻辑和新游戏：100种子状态边界、确定性重放、所有结局、行动门槛和坏存档拒绝。

`python scripts/check_space_browser.py` 默认仅操作一次性本地账号，真实浏览器检查头像、双用户聊天、邀请接受、撤回、游戏存档/结局和移动端布局。`--live` 只读验证线上公共页面、游客聊天室登录跳转及游戏，不创建线上账号、不写线上数据库。

## 2026-10-05 体验与性能优化

- Element Plus采用组件官方按需样式入口，不安装新插件；消息提示保留首屏样式，后台表格/分页/确认弹窗随各自路由加载。首屏CSS本地构建由约378.5KB降到约34.6KB（未压缩），gzip约7.8KB。`node frontend/scripts/check-bundle.mjs` 自动限制入口CSS≤100KiB、JS≤220KiB；已加入CI。
- 会话轮询不再反复写公共大厅行，仅首次初始化插入。私聊联系人/成员状态与双向拉黑批量读取；20个私聊场景验证总SQL语句不超过8条，没有轮询写入。未更改账号、权限或私聊同意规则。
- 会话列表标识待接受、已关闭、被拉黑的私聊；发送框跟随服务端状态禁用并解释原因，后端仍再次校验实际发送权。
- 阅读旧消息时保持原窗口和滚动位置，不自动跳到底部；新消息以提示和“回到最新消息”按钮呈现。分页渲染最多200条，继续向前时保留较旧窗口，仍可返回最新。与最新窗口重叠的撤回消息会同步，更旧条目需要重新加载。
- 草稿和失败重试消息标识在本次组件内按会话暂存，切换会话不丢草稿；刷新/离开聊天页面清除，不把聊天正文放进localStorage。现有登录令牌存储方案未变。
- 正常约12秒同步；失败逐步退避到24/48/60秒，成功恢复正常频率。页面隐藏或离开时取消读取、停止轮询，不自动重试有副作用的发送操作。
- 游戏的开始/重开滚动遵循系统减少动态效果偏好，不改变规则或存档版本。
- `python scripts/check_chat_history_browser.py` 本地专用模拟历史测试：长分页、锚点位置、刷新不丢历史、新消息提示、最新窗口恢复、后台停止/恢复、网络失败退避及手机布局。

样式入口依据：[Element Plus官方按需样式说明](https://github.com/element-plus/unplugin-element-plus)，路由样式拆分依据：[Vite官方CSS拆分说明](https://vite.dev/guide/features.html#css-code-splitting)。
