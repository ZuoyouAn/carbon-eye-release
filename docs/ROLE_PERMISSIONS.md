# 三档账号权限

| 功能 | 低权限 user | 高权限 elevated | 管理员 admin |
| --- | --- | --- | --- |
| 浏览公开内容 | 是 | 是 | 是 |
| 点赞、收藏、保存阅读进度 | 是 | 是 | 是 |
| 发帖、文章/帖子评论、留言 | 否 | 是 | 是 |
| 发布文章、管理站点内容 | 否 | 否 | 是 |
| 创建账号、禁言、删除用户、调整角色 | 否 | 否 | 是 |
| 查看权限变更记录 | 否 | 否 | 是 |

游客只能浏览公开内容。新注册默认低权限；原 user 账号仍为低权限，不批量提升已有账号。禁言账号不能发布内容；未知角色默认拒绝访问受保护接口。前端只提供提示，最终权限由后端根据数据库中的最新状态校验。

## 管理员如何提权

1. 登录后打开管理后台 → 用户。
2. 在目标账号行选择低权限、高权限或管理员，点击“调整权限”。
3. 确认变更并再次输入当前管理员密码。
4. 提升为管理员前，必须在目标用户的新密码栏输入至少 12 位、非常见弱密码的新密码。
5. 被调整账号的全部旧登录失效，需重新登录。权限记录显示操作管理员、目标用户、原/新权限和 UTC 时间，不保存任何明文密码。

管理员不能修改自己的角色，不能直接删除或禁言管理员。允许另一位管理员先调整管理员角色，再管理该账号；后端串行锁定管理员变更并重新校验操作者，避免并发互相降权。已删除的账号不能恢复或通过提权重新启用。

注册与普通用户修改接口拒绝额外角色字段，用户名 admin/root 为注册保留名，不能凭用户名获得权限。

## 一次性初始化 admin

在 Render 原后端服务的私密环境变量添加 `ADMIN_SETUP_PASSWORD`，使用至少 12 位、非常见弱密码的密码。不要将真实值写进代码或本文件。

- 当前没有 admin，且有正常的旧 root 管理员：把 root 改名为 admin、设置该私密密码，保留用户 ID 及所有关联内容，撤销旧令牌。
- 当前没有 admin/root：创建 admin，并记录初始化操作。
- admin 已是正常管理员：后续重启不重设密码，个人中心修改后的密码不会被旧环境变量覆盖。
- admin 已被低权限账号、已删除或禁言账号占用：拒绝自动提权或恢复，需要站点所有者排查。
- 初始化后建议从 Render 移除该一次性环境变量（删除操作请在 Dashboard 明确执行），以后从个人中心修改密码。

普通新密码至少 8 位，管理员新密码至少 12 位；旧密码哈希格式兼容。修改或重置密码、禁言/解禁、删除账号、调整权限都会撤销该账号旧令牌。
