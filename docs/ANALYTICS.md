# 统一访问统计

## 查看

登录左右的Space管理员账号，打开 `/admin` →「访问统计」。默认近 7 天，可切换近 30 / 90 天及「全部站点 / 左右的Space / 左右视频站」。显示今日 PV、今日 UV、所选范围 PV / UV、每日趋势、站点分布及热门页面。

统计从接入之后开始，不补算以前的访问量。匿名标识按站点独立去重，两站的同一浏览器会分别计数；UV 不是精确人数，清除本机存储、隐私模式和 30 天标识轮换会影响估计值。

## 方案与费用

- 不接第三方收费 Analytics、不创建新服务。复用现有 FastAPI、Neon、Netlify 和视频站 Render 免费实例；依然受这些平台原有免费额度限制，不承诺无限流量。
- 两站共用 `shared/traffic-tracker.mjs`，仅在生产页面路由改变时发送事件。主站直接发送到既有 API；视频站通过同域 `/api/analytics` 中继到固定后端，不新增跨站 Cookie 或放宽主站 CORS。
- 后端新增 `analytics_config`、`analytics_pageviews` 两张表，由已有启动流程创建。不修改已有账号、文章或聊天表。
- 管理员汇总 `GET /api/admin/analytics` 使用原有管理员鉴权，不对公众开放。普通用户 403、未登录 401；响应禁止缓存。

## 口径与隐私

- 仅统计允许的页面路径。查询参数全部丢弃，文章/帖子/小说详情统一归为 `/:id`；不保存搜索词、房间码、视频直链、标题、账号或 IP。
- 放映厅轮询、视频分片、接口、后台、登录/个人页、自动化浏览器与已识别机器人均不计入；主站管理员浏览也跳过。真实人、自动化识别与公网事件防伪均不完美，统计不可用于计费或安全审计。
- 浏览器首次生成随机 UUID，30 天后轮换；服务端用保存在数据库私有配置中的随机密钥做 HMAC，明细只保存哈希。密钥不下发、不写仓库、不借用账号密码。事件 UUID 作为幂等键，重试不重复计数。
- 近 90 天滚动展示；过期明细在下次上报或管理员查询时清理，服务长期休眠时不宣称实时清理。服务重启不丢失现有明细。
- 主站页脚与视频站「关于」均提供退出开关；尊重 DNT / GPC，不发送访客 Cookie、鉴权令牌和 Referer。退出会删除本机匿名标识并停止后续上报，但不承诺反向识别或删除过去的匿名汇总。
- 固定分钟窗口限制每标识 30 次、每来源网络 600 次、全局 2000 次上报，内存限 5000 个键。来源网络仅在内存保存带日盐 HMAC，不落库；跨服务中继共享网络配额。公开上报仍可能被伪造，后台已说明这一限制。

## 验证与维护

`python -m pytest -q`：含 23 项统计回归，测试使用临时 SQLite，不接生产数据。`node --test shared/traffic-tracker.test.mjs`：浏览器路由、隐私过滤、退出、自动化与幂等重试。视频站 Vitest 含 4 项固定目标中继安全回归；分别执行两站生产构建。

`scripts/check_analytics_browser.py` 使用固定样本只验证管理员页面及 390px 版面，不创建线上统计。`scripts/check_analytics_postgres.py --env-file <私密文件>` 仅允许已有 Neon 主机，使用 TEMP 表与外层事务回滚验证真实 PostgreSQL 去重、汇总、站点筛选，不读写现有公开表。凭据不打印、不提交。

共享跟踪文件从仓库根目录导入，部署必须保留 `shared/`。后续增加页面时同步维护后端与共享模块的允许路径，并补测试，避免记录自由文本路径。
