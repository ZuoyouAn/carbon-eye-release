# 2026-10-05 阅读与弱网体验

## 改动

- `latestRead.js` 只用于GET读取：同一通道的新请求取消旧请求，并校验请求身份。即使传输层忽略取消，旧响应或旧错误也不能覆盖最新结果。组件离开后取消读取，不再允许旧组件启动请求。参考 [Vue官方副作用清理说明](https://vuejs.org/guide/essentials/watchers.html#side-effect-cleanup)。
- 首页语录/统计离开页面即取消；文章/帖子首次直达详情不再额外下载列表或分类；小说导航列表只加载一次，详情并行获取。
- 列表/详情视图由当前路由决定，不由是否已读到内容决定。新详情加载时清空旧内容；错误使用常驻提示、重新读取和返回列表按钮，不伪装为“暂无内容”。文章、帖子和小说搜索支持回车并提供可访问名称。
- `GET /api/novels?include_content=false` 保留元数据字段，`content`返回空字符串，SQL不选择正文。搜索仍匹配正文；完整正文由详情接口读取。默认`include_content=true`兼容旧客户端，收藏/阅读进度元数据不变，无迁移或新增表。
- API客户端仅字符串请求体默认设置JSON Content-Type，无请求体的游客GET不再因该头触发跨域预检。登录请求的Authorization仍保留；有Bearer的跨域请求可能仍需预检，不修改CORS策略或登录方案。
- 用户取消、60秒超时、连接失败和非法JSON响应分别说明。空204响应返回null；非JSON错误仍保留HTTP状态。请求体/验证输入不放入用户错误提示。不自动重试任何写入操作。

## 验证

- Python新增3项：轻量列表默认兼容、正文搜索与用户收藏/进度、只读取元数据SQL。
- Node新增15项：最新结果胜出、旧错误忽略、取消/离开、可恢复错误、请求头、204、超时、断网、非法响应及401通知行为。
- `python scripts/check_read_resilience_browser.py` 只测试localhost；模拟故意忽略取消的传输，覆盖12项乱序读取、错误恢复、手机布局等。没有注册线上账号、生产写入或模型调用。
- 前端预算维持入口CSS≤100KiB、JS≤220KiB。

范围不包含登录存储方案迁移、离线缓存、PWA、聊天/WebSocket、支付或模型配置。写请求取消不代表服务端回滚；本轮只对读取应用最新响应机制。
