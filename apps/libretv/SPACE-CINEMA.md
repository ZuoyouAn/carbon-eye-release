# 左右大人服务：放映厅与 AI短剧发现

## 使用

1. 主站 `/libretv` 打开「左右大人服务」，输入原有影音访问密码，不是主站管理员密码。
2. 搜索影片并播放，点击「一起看」。或直接打开 `/cinema`，创建房间后填写有权使用的 MP4 / M3U8 直链。
3. 房主载入影片，默认在 0 秒暂停。复制邀请链接发给朋友；朋友也需验证网站密码，填写昵称加入。
4. 房主使用播放器播放、暂停、拖动、倍速和换片。成员播放器不展示进度控件，但可调本机音量、静音、全屏及发送评论。浏览器禁止自动播放时，点击「启用同步播放」。
5. 房主「结束放映」关闭房间。普通成员「离开放映」不会影响其他人。刷新保留同一标签页的角色；不要复制 sessionStorage 中的房间凭证给他人。

## 原理与边界

- `POST /api/cinema` 在已有密码会话保护下处理房间、控制和评论，无额外 HTTP 服务、WebSocket 服务或数据库。
- 服务端保存权威的媒体、时间锚点、进度、速度和递增版本。客户端每 1.5 秒拉取快照，用往返时间估计时钟偏移；成员每 250ms 检查偏差，大偏差跳转、小偏差轻微调速。房主每 5 秒校正当前播放位置。
- 房主身份来自随机成员凭证对应的服务端记录，不相信请求里的 `role`。伪造的播放、暂停、seek、rate、media 请求一律返回 403；过期控制序号、频繁指令、超大请求受限制。
- 邀请链接只含随机房间码，不含控制令牌或播放地址。成员凭证只在该标签页 sessionStorage；服务端只保存其 SHA256 摘要。获邀成员可以看到本房间媒体地址与评论，请勿填敏感签名地址或个人资料。
- 最多 20 个房间，每间最多 8 人。连续评论限制为每人 10 秒 6 条、每条 300 字；服务端保留最近 80 条，快照最多带最近 40 条。评论作为纯文本渲染。
- 房间最多存在 8 小时，无活动 2 小时回收；房主离线超过 20 秒冻结时间轴并暂停。未活跃观众超过 90 秒可以被新加入者回收名额。房主不会自动移交权限。
- 房间及评论仅存于单个 Node 进程内存，不是永久记录。免费实例休眠、部署、重启都会丢失；本实现必须单实例运行，多实例需要另做共享状态与顺序控制。
- 各设备自行拉取同一媒体，不是分享屏幕或复制会员权益。直连失败会尝试已有安全代理，受服务器带宽额度限制。只支持固定时长的点播，不做 DRM 绕过、平台网页解析和直播时间轴。
- 网络、缓冲与设备解码会影响同步，不承诺逐帧一致；有人缓冲时请房主暂停等待。后台节流可能使房主心跳失效，需保持页面活跃。

## AI短剧入口

`/ai-drama` 提供 AI短剧、AI漫剧、AIGC短剧等关键词，接入现有影视源的站内搜索，以及哔哩哔哩、抖音官方站点的外部搜索链接。关键词页不会将不可靠的解析接口伪装成免费官方片源，平台搜索可能需要登录或受地区限制。

官方资料仅用于发现与核实行业内容，不表示允许任意转播：

## 维护与验收

运行 `npm test`、`npm run lint`、`npm run typecheck`、`npm run build`。新增 store 与路由测试覆盖角色伪造、房主失联、重放、非法媒体、跨站请求、限流、房间容量及过期。

仓库根目录的 `scripts/check_cinema_browser.py` 使用两个独立 Edge 会话、公开 CC0 示例视频进行真实播放/暂停/跳转/调速、成员越权拒绝、评论互通、刷新保留身份、390px 布局与关闭房间检查。生产测试只从明确指定的私密凭据文件读取密码，不在参数或日志输出密钥；测试结束主动关闭所创建的房间。
